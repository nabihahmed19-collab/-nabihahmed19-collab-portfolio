Multi-Output CNN: Age, Gender & Ethnicity

A multi-output ResNet50 trained on UTKFace to predict age, gender, and ethnicity from a single face image.

ResNet50 Computer Vision Multi-task Learning
View on GitHub
Context

A single-image facial attribute prediction task using the UTKFace dataset.

The Problem

Predicting age, gender, and ethnicity from one photo means training three very different kinds of tasks — a near-binary classification, a multi-class classification, and a regression — inside one shared model. Naively combining their losses lets one task dominate the others during training.

Skills Used
Python TensorFlow/PyTorch ResNet50 Transfer learning Multi-task loss balancing
Approach

Built a multi-output ResNet50 with three separate prediction heads, then tuned the loss weighting across the three tasks so each head actually learned rather than one drowning out the others.

Result

90.9% gender classification accuracy and ±6.6-year mean absolute error on age prediction, in a single forward pass through one model.
