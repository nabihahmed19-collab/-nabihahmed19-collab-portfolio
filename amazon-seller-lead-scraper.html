Amazon Seller Lead Scraper

A Selenium-based scraper that pulls Amazon seller leads and exports them straight to Excel for outreach.

Selenium Python Excel
View on GitHub
Context

Built with Maaz to replace a manual, copy-paste lead research process for outreach.

The Problem

Manually browsing Amazon seller pages and copying data into a spreadsheet for outreach took real time and didn't scale past a handful of leads a day.

Skills Used
Python Selenium Excel export
Approach

Built a Selenium script that navigates seller pages, collects the relevant data, cleans it, and exports it directly to Excel in a format ready to hand to outreach.

Result

Turned an afternoon of manual research into a single script run, end to end.
